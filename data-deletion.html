Data Deletion

DCPMOD stores operational data locally on the user's Windows computer. The developer does not maintain a remote user database.

1

Disconnect Google access

Open Google Account → Third-party connections, select DCPMOD and remove access. This prevents future access through YouTube API Services.

2

Close DCPMOD

Use the application's “Close bot” control and make sure the program is no longer running before removing its files.

3

Delete local application data

Remove DCPMOD's local data folder shown by the application. This deletes its saved OAuth token, settings, moderation logs, counters and cached records.

4

Need help?

Open a request on the DCPMOD support page on GitHub. Do not publish passwords, OAuth tokens or other secrets.
