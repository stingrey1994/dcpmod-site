Privacy Policy

This policy explains how DCPMOD uses information obtained through YouTube API Services and data stored by the desktop application.

1. Application and contact

DCPMOD is a private Windows desktop moderation tool operated by its individual developer. Privacy questions may be submitted through the DCPMOD support page on GitHub. Do not include passwords, OAuth tokens or secrets in a public issue.

2. Information accessed

After Google OAuth 2.0 authorization, DCPMOD may access the authorized account's public channel identity and authorization status; active or upcoming live-broadcast and live-chat identifiers; live-chat messages and public author information such as channel ID, display name, role and timestamp; and results of authorized moderation actions. DCPMOD does not request or store a Google password.

3. Use of information

Information is used only to display live chat, apply user-configured filters, detect spam, execute authorized moderation actions, provide configured chat features, and create local logs and basic analytics. DCPMOD does not sell YouTube API data, use it for advertising, or build advertising profiles.

4. Storage, sharing and retention

DCPMOD is local-first. OAuth credentials, configuration, moderation history and statistics are stored on the user's computer in the application data directory. Data is not transferred to the developer or sold to third parties. Google and YouTube process information as required to provide their services. Local records remain until the user removes them.

5. YouTube and Google

DCPMOD uses YouTube API Services. By using DCPMOD, the user also agrees to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

6. Revocation and deletion

The user can revoke DCPMOD's Google access at any time on the Google Account third-party connections page. Revocation prevents future API access but does not remove existing local files. Instructions for removing tokens, logs and other local data are on the Data Deletion page.

7. Security

DCPMOD uses OAuth 2.0 and stores authorization material locally. Users should protect their Windows account and never share OAuth tokens, client-secret files or the application data directory.

8. Children

DCPMOD is an operator tool intended for an adult channel owner or authorized moderator. It is not directed to children.

9. Changes

This policy may be updated when the application's practices or legal requirements change. The effective date identifies the current version.
